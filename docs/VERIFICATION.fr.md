# Vérification PixelStella v0.2.0 — 23 novembre 2026

Types TypeScript stricts et compilation validés. **19 tests unitaires/HTTP/migration/traduction réussis, aucun échec final.** Sources et EXE portable ont chacun réussi les mêmes 10 groupes de parcours bureau et 4 groupes de langues (trois langues et persistance après redémarrage). Pour chaque mode : 3 langues × 4 pages × 2 largeurs (830 et 1230), soit 24 contrôles axe/mise en page, sans violation signalée ni débordement horizontal. Les quatre états d'accessibilité d'origine réussissent aussi dans chaque mode. Aucune exception d'interface non interceptée ni requête HTTP externe de l'interface enregistrée.

Les tests vérifient formulaire, compagnon, reconstruction réelle du menu de notification, erreurs IPC, message de fin du minuteur et conservation des textes chinois de l'utilisateur. La migration conserve octets et images d'origine, refuse corruption et conflits et n'écrase aucune sauvegarde existante. Un sélecteur de test ambigu a été corrigé puis tous les tests relancés ; les tentatives échouées ne comptent pas comme réussites. Les boîtes de fichiers sont remplacées par des données synthétiques. Le temps du processus est simulé sans modifier l'horloge Windows.

Rapports dans test-results/, ignoré par Git : desktop-results.json, portable/desktop-results.json, i18n/results.json et i18n-portable/results.json. Les captures publiques utilisent un autre profil synthétique vide. CHECKSUMS.txt couvre environnement, application compilée, ressources et documentation. Aucun profil privé ni poids de modèle n'est inclus. Aucune publication ni poussée GitHub.

Non validés : IA réelle/GPU/qualité, autre PC Windows vierge, réception des notifications système, lecteur d'écran, boîtes natives manuelles, DPI multiécran, veille et longue durée. Les boutons Windows suivent la langue système. Une relecture humaine des traductions reste souhaitable. Dépendances inchangées, sans nouvel audit en ligne ; l'ancien audit reste historique. Aperçu portable non signé, sans installateur Setup. Voir le [rapport détaillé chinois](VERIFICATION.md).
