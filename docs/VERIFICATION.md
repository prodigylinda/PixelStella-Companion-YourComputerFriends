# PixelStella v0.2.0 验证记录

日期：2026-11-23（Asia/Shanghai）。本轮完成正式名称与中文、英文、法文接入，没有推送 GitHub、部署公网或下载绘图模型。

## 本轮修改

- 项目目录、包信息、GitHub 地址、窗口、托盘、程序名统一为 PixelStella；仓库名为 PixelStella-Companion-YourComputerFriends。
- 主窗口、角色工坊、计划表单、专注、设置、桌宠、系统菜单、通知文案、错误提示和日期支持中英法切换；语言保存后重启恢复。Windows 原生按钮仍由操作系统决定语言。
- 只翻译程序拥有的静态文本，动态插入的角色名、计划、备注和 AI 提示词不翻译。小窗口和长法文标签支持换行。
- 新资料目录为 %APPDATA%\PixelStella。无新版存档时只复制旧 %APPDATA%\Xingban 的存档和引用图片，不改旧文件、不覆盖已有新版存档；异常数据或图片冲突会停止迁移并提示。已有 v1 存档缺少语言字段时默认中文。
- 中英法 README、使用说明、隐私和开发指南；六张来自实际空白测试存档的三语言展示截图。
- 构建、干净源码导出和便携版脚本更新；完整文件 SHA-256 清单，项目许可证与 Electron 许可证分开保留。
