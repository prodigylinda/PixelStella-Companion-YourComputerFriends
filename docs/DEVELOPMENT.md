# PixelStella开发指南

一个在 Windows 本机运行的角色桌宠与学习提醒项目。角色可以悬浮、拖动，陪你记录计划、按时提醒和安静专注。第一版不需要登录，没有云同步或遥测。

## 先体验

完成打包后，打开 `release/PixelStella-v0.2.0-win-x64/PixelStella.exe`。它带有运行环境，不需要另装 Python、Node.js 或浏览器。整个文件夹一起保留，不能只复制 EXE。当前是未签名的便携开发预览版，不是安装器。

源码工作目录也可以双击 `start-windows.bat`。该启动器使用已安装在项目内的 Electron，不修改 PowerShell 执行策略。首次从干净源码安装请先看下面的开发说明。

主窗口关闭后会收进 Windows 系统托盘；双击托盘图标或点击桌宠上的星星按钮重新打开。要真正停止提醒，请从设置或托盘选择“退出PixelStella”。第一次使用请自行安排一条临近的测试计划，检查你电脑上的通知设置。

## 当前功能

- **离线角色定制**：原创 Q 版人形、猫耳、兔耳、狐狸，搭配发型、表情、配饰、肤色、发色和衣服颜色。即时预览、保存并同步到桌面。这是程序绘制的矢量定制，不是 AI 生成。
- **图片角色**：导入本地 PNG/JPG/WebP，作为桌面角色展示。限制 8 MB、4096 × 4096，并规范化为不超过 1024 像素的 PNG。透明 PNG 更适合悬浮。普通照片不会自动转 Q 版或抠图。
- **学习计划**：新增、编辑、删除、完成一次性计划；每天或工作日重复计划可暂停/恢复。支持学科、备注、日期与时间，按今天或全部筛选。
- **双重提醒**：应用内消息、桌宠气泡；非安静模式还会尝试 Windows 系统通知。可以从桌宠选择 5 分钟后再次提醒。触发记录在本机持久保存，避免同一次提醒在重启后反复发送。
- **启动补发**：只补发最近 24 小时错过的提醒；重复计划只补发最近一次。过旧的提醒不自动补发。彻底退出应用时无法发送即时提醒。
- **专注计时**：15/25/45 分钟选择，暂停、继续与重置，到时提醒。关闭主窗口继续运行；完全退出后仅能在下次启动检查已结束的计时。
- **偏好**：显示/收起桌宠、置顶、80%–130% 大小、安静陪伴。计划可导出 JSON；离线定制角色可导出透明 PNG；导入或生成的图片保留其原有背景。
- **可选本机 AI**：兼容 Stable Diffusion WebUI 的文字生成接口；需要用户自己安装模型。没有模拟生成，没有自动下载大型模型。

桌宠可拖动，右键角色可打开菜单。当前没有自动游走、Live2D 骨骼动作、语音交互、读取其他软件通知或开机自启；没有把这些列为已完成功能。

## Windows 通知的实际边界

应用会区分“应用内提醒”和“已发起系统通知，送达未确认”。`Notification.isSupported()` 只表示 API 支持；系统勿扰、通知权限及应用注册可能阻止横幅。Windows 原生横幅和通知中心需要在目标电脑人工验收，不能仅凭 API 调用认定已送达。未注册的开发/便携应用尤其需要检查。

不要把本项目当作闹钟、紧急通知或系统后台服务的保证。电脑关机、应用彻底退出、睡眠和系统时间变化都会影响实际提醒时机。数据使用当前设备本地日期和时间。

## 接入真实本机绘图模型

1. 自行安装并运行 AUTOMATIC1111 Stable Diffusion WebUI，按照其文档下载你有权使用、适合显卡的模型。下载和模型许可由你决定，本项目不会自动安装它们。
2. 在 WebUI 启动参数中启用 `--api`，保持监听回环地址，不要为了本项目将它暴露到公网。
3. 在角色工坊填入 `http://127.0.0.1:7860`，点击“检查本机接口”。这会读取 `/sdapi/v1/sd-models`，不会发送照片或计划。
4. 输入角色描述，明确点击“生成并设为角色”。调用 `/sdapi/v1/txt2img`；最长等候 120 秒。返回的图片经过本机解码验证后才设置为角色。

接口仅接受 HTTP 回环地址（127.0.0.1、localhost、::1），不接受远程地址、凭据、查询参数或任意路径。不提供云端密钥输入框。当前只有文字生成，**没有照片参考生成/本人照片转 Q 版，也不保证生成图透明或与描述完全一致**。需要这类能力时应另行选择合适模型与工作流。

本机接口不等于第三方绘图软件一定离线；请核对它的扩展、代理和云端转发设置。AI 失败会显示明确错误，不会用矢量预设角色伪装成生成结果。当前环境未安装绘图模型，不能宣称真实 AI 推理已验收。

## 开发

技术栈：Electron、TypeScript、原生 HTML/CSS/SVG、Node.js 内置测试、Playwright 和 axe-core。没有服务端或数据库服务；存档是经过校验并原子替换的本地 JSON。

要求 Node.js 24 或更新版本、pnpm 11。使用锁文件安装依赖：

```powershell
pnpm install --frozen-lockfile
# Electron 下载脚本是显式步骤；其他构建脚本没有自动批准执行。
node node_modules/electron/install.js
pnpm build
pnpm start
```

受限开发环境中可将 `TEMP`/`TMP` 和 `electron_config_cache` 指向新的工作区临时目录。Electron 内部沙盒始终启用；不要通过 `--no-sandbox` 解决 Windows 权限问题。若运行时明确报告 AppContainer 无法读取 Electron 的运行时，只应由设备维护者按错误信息对该运行时目录检查读取/执行权限，不能更改用户照片或数据目录的广泛权限。

```powershell
pnpm typecheck
pnpm build
pnpm test
pnpm test:e2e
pnpm audit
pnpm package:portable
```

桌面测试使用 `PIXELSTELLA_TEST=1` 和独立临时存档；该变量不是功能开关，也不加载真实用户数据。测试覆盖系统调度时会明确模拟当前进程时钟，不修改 Windows 系统时间。验证结果见 `docs/VERIFICATION.md`。

## 目录

```text

scripts/           构建和 Windows 便携版打包
tests/             核心测试及真实 Electron 端到端测试
docs/              验证报告
dist/              编译产物，不是源码
release/           带运行环境的便携文件夹
test-results/      合成测试记录与界面截图
```

## 数据与更新

正常运行数据保存在 `%APPDATA%\PixelStella`，程序文件和用户存档分开。手动替换程序目录不会主动覆盖存档。更新前建议复制备份该数据目录；当前只支持版本 1 存档，不声称任意未来版本都能兼容。

便携版本身不写注册表、不创建开机任务、不永久修改系统策略。删除程序文件夹即可移除程序，用户数据会保留；若想清理数据，请先退出并自行备份后删除 `%APPDATA%\PixelStella`。没有静默自动更新或 Windows 安装/卸载向导。

进一步的数据说明见 [PRIVACY.md](../PRIVACY.md)。原创角色图形由本项目程序绘制，不附带第三方角色素材或模型权重。导入他人图片或使用第三方模型时请自行确认相应使用权。

参考：[Electron 安全建议](https://www.electronjs.org/docs/latest/tutorial/security)、[系统通知 API](https://www.electronjs.org/docs/latest/api/notification)、[WebUI API](https://github.com/AUTOMATIC1111/stable-diffusion-webui/wiki/API)。
