# PixelStella v0.2.0 verification — 2026-11-23

Strict TypeScript checks and build passed. **19 unit/HTTP/migration/localization tests passed; none failed.** Source and portable EXE each passed the same 10 desktop workflow groups, plus 4 localization groups (three languages and restart persistence). Each run checked 3 languages × 4 pages × 2 widths (830 and 1230): 24 axe/layout checks, no reported violations or horizontal overflow. Four original accessibility states also passed in each run. No uncaught renderer errors or external renderer HTTP requests were recorded.

Language tests cover the dialog, pet, actual tray-menu rebuilding, IPC errors, scheduler-generated focus messages and unchanged user-authored Chinese text. Migration tests preserve original bytes and images, reject corruption/conflicts and never replace an existing save. One ambiguous test selector was corrected and all tests rerun; failed attempts are not counted as passes. Native file dialogs are replaced with synthetic fixtures, and timer completion uses an explicitly simulated process clock, never the Windows clock.

Reports live in ignored test-results/ (desktop-results.json, portable/desktop-results.json, i18n/results.json, i18n-portable/results.json). Public screenshots use a separate empty synthetic profile. The portable CHECKSUMS.txt covers the entire runtime, compiled app, resources and documentation. No private profiles or model weights are bundled. No GitHub push or public deployment occurred.

Not validated: real AI inference/GPU/quality, another clean Windows machine, OS notification delivery, screen-reader use, native dialogs by hand, multi-display DPI, sleep/resume and long-running behavior. Windows buttons use the OS language. Human proofreading of translations remains welcome. Dependency versions did not change; no new online audit was run. Existing older audit results are historical only. This is an unsigned portable preview, not a Setup installer. See the detailed [Chinese report](VERIFICATION.md).
